1. Four Critical Bottlenecks of Enterprise AI Adoption
Part I: Pain Points & Challenges
1. Hallucination Trap

Pure prompting causes LLMs to fabricate metrics and prices. Missing hard citations creates fatal legal and compliance risks.

2. Token Bloat & Latency

Feeding all user stocks (20+ tickers) into a single prompt consumes 30k+ tokens, causing 12s+ latency and token waste.

3. Multi-Tenant Leakage

Without database security rules and token masking, portfolios, webhooks, and private chat histories risk cross-user leakage.

4. Data Disparity & Rumors

Mixing unverified Reddit/X rumors with quantitative feeds without sanitization ruins research rigor and triggers false trades.

5. Multi-Tenant RBAC & Zero-Trust Privacy Defense
Part IV: Multi-Tenant & Security
🛡️ Cryptographic Firestore Isolation (firestore.rules)
  • Strict Rule Enforcement: Direct client SDK access is restricted to request.auth.uid == userId.
  • No Client User ID Parameter: Backend extracts uid strictly from Google-signed JWT Bearer tokens; passing arbitrary user_id in body/query is rejected.
  • Shared Read-Only Caches: stock_pools and macro_cache allow authenticated reads, but require Admin SDK writes.
🔑 Dynamic Webhook Secret Masking
  • One-Way Masking: WeChat Work (key=36a2****6987) and Discord (.../f0C3****q6tk) are masked in responses to prevent token exposure.
  • Non-Destructive Updates: When updating settings with masked inputs (containing ****), backend preserves existing stored credentials.
  • Tier Matrix Quotas: Free (1 holding), Trial (5 holdings, 2 observe), Paid/Pro (15 holdings, 5 observe, 15-day grace period), Super/Admin (unlimited).
6. Multi-Source External Data Rigor & Sanitization Pipeline
Part IV: Data Engineering
FMP & yfinance Golden Source
  • FMP Primary: Quotes, VWAP, technical indicators, 13F institutional ownership, insider trades, SEC transcripts.
  • Sanitization: Validates $P > 0$, $RSI \in [0, 100]$, and discards corrupted or stale data.
  • yfinance Fallback: Smooth circuit breaker fallback for macro ETF continuity.
FRED Official Federal Reserve
  • 9 Core Series: 10Y-2Y Spread (T10Y2Y), 10Y/2Y Yields, Fed Funds (FEDFUNDS), Core PCE, CPI, Nonfarm Payrolls, Unemployment Rate, Consumer Sentiment.
  • Sanitization: Filters missing . markers; attaches official release dates with 15-min TTL cache.
Media & Social Rumor Filter
  • Tier-1 Media: Domain priority filtering for Bloomberg, Reuters, WSJ, CNBC, Seeking Alpha.
  • Social Pulse: Demarcates Reddit WSB & X chatter.
  • Rumor Warning Badge: Automatically prepends ⚠️ [Unverified Social Rumor] to prevent misinformation.
7. Seven-Fold Autonomous Self-Healing SRE Closed Loops (MAPE-K)
Part V: Loop Architecture
🤖 1. AI Format Self-Audit Loop

Pydantic intercepts Gemini output; validation failures assemble Reflection Error Prompt for re-reasoning (up to 3 retries).

⚡ 2. API State Machine Circuit Breaker

FMP failures trip breaker (CLOSED ➔ OPEN), triggering seamless fallback to yfinance or Firestore cache.

🔍 3. Cache Miss Self-Fill Loop

Cloud Scheduler scans Firestore missing cache and executes Prewarm prior to report dispatch.

📊 4. Gems Win Rate Evolution Loop

Scans past 30-day stock signals vs T+5 actual prices, calculating profit factor and emitting OPTIMAL/CRITICAL ratings.

🚨 5. Unhandled SRE Feedback Loop

FastAPI error interception connects to GCP Error Reporting and dispatches Discord alerts with fix suggestions.

🛡️ 6. Runaway Sanitizer & Rate-Pacing

Eliminates degenerate table delimiter loops and enforces 5-chunk caps with 0.35s sleep to prevent WeChat/Discord rate limits.
